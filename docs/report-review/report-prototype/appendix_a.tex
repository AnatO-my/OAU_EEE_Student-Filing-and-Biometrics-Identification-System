\chapter{Supporting Evaluation Evidence}\label{app:evidence}
\textbf{Supporting material pending.} Add de-identified trial protocols,
test-case summaries and suitably redacted evidence that supports Chapter Four.
The source-notes directory contains the original draft evidence index and
materials review for the team's use; those internal notes are not automatically
included as submitted academic material.

Do not insert raw fingerprint captures, biometric references, real student
records or credentials into a shared report project. Use approved, de-identified
evidence and cite the dataset or test record associated with each result.
