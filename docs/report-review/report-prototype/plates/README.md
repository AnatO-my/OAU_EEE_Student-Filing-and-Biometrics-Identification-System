# Photographs and screenshots

Place approved prototype photographs here (JPG, PNG or PDF). No project
photographs were present in the supplied report-review materials, so none have
been invented. Keep student records, fingerprints and credentials out of images.

Example to add in a chapter after uploading a photograph:

```latex
\begin{plate}[htbp]
  \centering
  \includegraphics[width=0.8\linewidth]{plates/prototype.jpg}
  \caption{The assembled prototype}
  \label{plate:assembled-prototype}
\end{plate}
```

Mention `Plate~\ref{plate:assembled-prototype}` in the surrounding text.
