# Tables

The 13 tables from the three chapter drafts are individual `.tex` files here.
Chapters include them with `\input{tables/table_3_1}` etc. Edit the included file
to change its contents. They use booktabs rules, single spacing, repeated header
rows and longtable page breaks. Wide tables use landscape pages.

Table numbers are generated from their chapter and sequence, not their filenames.
Keep `\label{tab:3-1}` and references consistent if reorganising the chapters.
