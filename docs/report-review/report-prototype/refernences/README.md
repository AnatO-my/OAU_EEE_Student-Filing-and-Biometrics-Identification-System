# Bibliography

The folder spelling `refernences` follows the requested project layout.
`references.bib` contains 17 entries transcribed from the supplied working
reference lists; publication metadata has not been independently re-verified.

Use `\cite{gill1993}` or `\cite[pp. 3--6]{gill1993}` in a chapter. The report
style selects IEEE references with Biber. Do not load another bibliography
package. Working author-year citations in the source drafts were converted to
numeric citations while retaining narrative author names and supplied locators.

If renaming this folder to `references`, also update `\addbibresource` in main.tex.
